# Проект: Мир Света

Информационная система магазина осветительных приборов. 
Разработана в рамках производственной практики (ПМ.11).

## Технологии
* Python 3 (Tkinter)
* PostgreSQL (psycopg2)
* Pillow (работа с изображениями)

## Основные функции
* Каталог товаров с фото и подсветкой остатков.
* Оформление заказов с выбором цвета (Белый, Чёрный, Серебристый).
* Автоматический расчет скидки 25% (если товара не было в заказах в прошлом месяце).
* Ролевая система (Клиент, Менеджер, Администратор).
* Панель администратора для управления заказами.

## Структура Базы Данных
База данных состоит из 6 таблиц: `Роль`, `Пользователь`, `Вариант`, `Товар`, `Заказ`, `Состав_заказа`.
Скрипт для создания БД находится в файле `init_db.sql`.

## Установка и запуск
1. Создайте БД `init_db` в PostgreSQL.
2. Выполните скрипт `init_db.sql`.
3. Настройте доступ к БД в файле `config.py`.
4. Установите зависимости: `pip install -r requirements.txt`.
5. Запустите: `python main.py`.
